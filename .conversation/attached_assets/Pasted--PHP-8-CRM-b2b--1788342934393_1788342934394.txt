Ты — ведущий PHP-разработчик с 8-летним опытом создания интернет-магазинов и CRM-систем для b2b-сектора (HoReCa). Твоя задача — написать работающий код для моего проекта.

Мне нужно создать минимально жизнеспособный продукт (MVP) на чистом PHP для интернет-магазина расходных материалов для кафе (салфетки, перчатки, чистящие средства).

---

ТРЕБОВАНИЯ КОДУ:

1. Файловая структура (создай ВСЕ перечисленные файлы):

· index.php (главная страница с каталогом)
· admin.php (админ-панель для управления заказами)
· functions.php (все функции для работы с БД, корзиной, расчетами)
· style.css (полностью стилизованный дизайн)
· db.sql (скрипт для создания таблиц в MySQL)

2. База данных (в db.sql):

· Таблица products: id, name, price, quantity (остаток), category, image_url.
· Таблица orders: id, client_name, phone, total_sum, status (по умолчанию 'новый'), created_at.
· Таблица order_items: id, order_id, product_id, quantity, price_at_moment.

3. Функционал на index.php (фронтенд для клиента):

· Вывод всех товаров из БД карточками (с ценой, названием, остатком).
· Строка поиска сверху (фильтр по названию через LIKE).
· Кнопка "В корзину" с AJAX-запросом (без перезагрузки страницы) — отправка данных в cart.php через fetch API.
· Корзина (popup или отдельная страница) с возможностью изменения количества товаров, автоматическим пересчетом итоговой суммы.
· Форма оформления заказа: Имя, Телефон, Адрес (для b2b это важно).
· После отправки заказа — показывать сообщение: "Спасибо! Заказ №XX принят".

4. Функционал на admin.php (CRM для кореша/менеджера):

· Авторизация через базовый логин/пароль (логин: admin, пароль: 123456).
· Таблица всех заказов с колонками: №, Клиент, Телефон, Сумма, Статус, Дата.
· Кнопки рядом с каждым заказом: "Обновить статус" (выпадающий список: Новый / На сборке / Передан в доставку / Выполнен).
· Внизу статистика: "Всего заказов: X | На сумму: Y руб.".

5. Функционал в functions.php:

· connectDB() — подключение к MySQL.
· getProducts() — получение всех товаров.
· addOrder($data) — сохранение заказа и его товаров в БД.
· updateOrderStatus($id, $status) — обновление статуса заказа.
· Все запросы выполнять через PDO (защита от SQL-инъекций).
